# 旧代码库归档说明

本目录保存项目早期版本和备份。静态导入检查确认：当前
`core/TrackFood.py`、`field/` 和 `tools/` 均没有导入这里的文件。

这些文件只用于追溯历史思路，不属于当前可运行主线。不要把它们直接复制回
`core/` 覆盖现有代码。

| 文件 | 历史用途 | 当前状态 |
|---|---|---|
| `TrackFood_AutoRecover.py` | 早期自动恢复版主程序 | 已被当前 reset/relabel 流程替代 |
| `auto_tracking_utils.py` | 配套自动恢复工具函数 | 仅服务旧版 |
| `TrackFood_test_chunk12.py` | 早期 chunk 测试版本 | 仅供对照 |
| `TrackFood_v2_bak.py` | 旧主程序备份 | 仅供对照 |
| `FieldTempMonitor_backup.py` | 现场监控旧备份 | 已由 `field/` 当前版本替代 |
| `food_labels_v2_bak.json` | 旧标注格式样本 | 不对应当前 test8_1 |
| `way.docx` | 体积较大的早期过程文档 | 内容需人工查看，不参与运行 |

## 使用原则

1. 默认只读。
2. 需要比较旧算法时，在独立分支或副本中运行。
3. 旧文件中的路径、阈值和输出格式可能已失效。
4. 旧版可能直接写入当前 `output/` 或配置文件，运行前应先检查。
5. 当前目录未被主线调用，删除与否不会改变当前运行结果；但用户已决定暂时
   保留历史参考。
