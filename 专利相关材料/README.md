# 专利相关材料归档说明

本目录保存技术交底、阶段总结、专利附图和生成脚本。它不参与
`core/TrackFood.py` 运行。

## 目录内容

| 路径 | 用途 |
|---|---|
| `技术交底书模板_readonly_copy.doc` | 原始技术交底书只读副本 |
| `patent_template_extract/` | 模板转换后的 DOCX 和文本提取 |
| `Chef_Vision_技术总结报告.docx` | 阶段技术总结 |
| `当前方案汇总.pdf` | 阶段方案汇总 |
| `pdf/` | 早期架构/优化思路 PDF |
| `generate_tools/` | 专利附图和架构图生成脚本 |
| `gen_report.py` | 早期技术报告生成脚本 |

## 当前定位

- 专利已交给代理机构，本目录作为材料归档和后续补充依据。
- 当前代码已经继续演化，尤其是最终温度决策、统一 IR 分割、正反向 reset
  和模块化状态，旧 PDF 不一定覆盖最新实现。
- 根目录 `Chef_Vision_项目总说明.pdf` 用于解释当前代码，不替代正式专利
  文件，也不自动改写已交付的交底书。

## 注意事项

1. 不要覆盖原始模板和已交付版本。
2. 生成脚本可能依赖特定字体、Office 转换工具或旧输出路径。
3. 重新生成附图前先核对脚本中的路径。
4. 专利材料中的范围可以高于当前代码原型，但对“已经实现”的描述应有代码
   或测试结果支撑。
5. 本目录的 Python/PowerShell 文件属于归档生成工具，不是主程序模块。
